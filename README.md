\# Password Strength Checker



A simple Python script that checks how strong a password is. It looks at:

\- Length (8+ characters)

\- Uppercase letters

\- Lowercase letters

\- Numbers

\- Special characters



Based on how many checks pass, it rates the password as \*\*Weak\*\*, \*\*Medium\*\*, or \*\*Strong\*\*.



\## How to Run



1\. Make sure Python is installed

2\. Run the script

3\. Enter a password when prompted

4\. See the strength rating
